# Runtime map gaps are owned work

When source contracts define a richer runtime architecture than the AppSDK function or mainline map, that mismatch is a governance gap to record and repair through the unique map owner. It is not evidence that the runtime architecture does not exist and not permission to invent symbols or claim full binding.
