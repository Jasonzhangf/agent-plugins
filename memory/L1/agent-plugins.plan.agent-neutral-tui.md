# Agent-neutral TUI boundary

agent-tui is intended to provide one agent-neutral TUI protocol and presentation surface. Concrete agent protocols belong behind the AgentHost/AgentRemote adaptor boundary; ACP adaptor family and selection are an extension target, not a claim that multiple ACP agents are currently implemented.
